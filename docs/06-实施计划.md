# cswap · 实施计划

> 进度（2026-11-07）：P0–P5 代码已完成，`swift test` 36 项通过，Snapshot 各场景自查过；待用户真机验收。P6 待用户确认。

按阶段推进，每阶段结束都要：`swift test` 通过、`swift run Snapshot` 出图自查、阶段结论写进交接记录（memory-keeper `handoff/<分支>`）。真机效果（菜单栏、毛玻璃、通知）终端验不了，交给用户看。

功能编号对应 `02-功能清单.md`。

## P0 · 工程骨架（约半天）

- SwiftPM 工程：`CswapCore` / `CswapUI` / `CswapApp` / `Snapshot` / `CswapCoreTests`，`Package.swift` 带 TestingMacros 插件加载（抄 NetHub）。
- 从 NetHub 复制 `Theme.swift` 改名；拷贝 `assets/` 里的托盘模板图和 Claude 星形到 `Resources/`。
- `NSStatusItem` 显示模板图标 + 固定文字；点开弹出空面板（NSPanel，失焦关闭）；单实例。
- `tools/package.sh` 能打出 `cswap.app`。

**验收**：`swift build`、`swift test` 通过；打包产物能启动，菜单栏出现图标，点开有面板。

## P1 · 数据层（约 1 天）

- `CLI.swift`：定位 cswap、干净环境、超时、读写分离、JSON 错误解码（见 04 §4、05 §3）。
- `Models.swift`：解码 `list / status / config --json`；`PriorityParser`；`SwitchLog`。
- `Overview.swift`：状态判定、进度条颜色级别、档位识别、刷新时间文案、节奏提示、阈值预告（规则见 03 §3–§6）。
- 测试：用 `fixtures/` 真实输出 + 手造边界数据（usage 为 null、无 5 小时窗口、token_expired、expired 套餐、未知 tier、scoped 窗口）。

**验收**：单测覆盖上述映射；`Snapshot` 能用 fixtures 渲染出假数据面板。

## P2 · 主面板（约 1 天）

- B1–B6、B9、B11（只做开关显示）、B13；A1–A2。
- 定时刷新、面板打开即刷新、切换后立即刷新。
- Snapshot 场景：现在（fixtures）、四个档位、快到阈值、都用完、读不到、登录失效 × 浅 / 深。

**验收**：Snapshot 图与 `design-demos/a4.html` 对照无明显偏差；用户真机看菜单栏和面板并点切换。

## P3 · 账号操作（约 1 天）

- B7 菜单、B8 添加、B10 失效行「刷新」、C1–C11 账号详情与全部操作。
- 移除走系统确认框；「刷新」先核对当前登录邮箱。

**验收**：每个操作在真机上走一遍并用 `cswap list` 交叉核对结果；**移除账号只用测试账号或先问用户**（不可逆）。

## P4 · 自动切换（约 1 天）

- D1–D8；AutoSwitchService（启动、事件解析、退避重启、设置变更重启、退出清理）；B12 阈值预告。
- Snapshot：自动切换设置页。

**验收**：开关能启停子进程（`ps` 核对）；改阈值后子进程重启；用 `cswap auto --json --dry-run` 或临时调低阈值验证事件能被解析（**不要在用户正用的会话上制造真实换号，先问**）。

## P5 · 通用设置、通知、记录、升级（约 1 天）
