# cswap · 决策记录

记录用户拍板的结论**以及被否掉的方案**，防止后来者重提。日期均为 2026-11-07。

## 技术路线

| 决策 | 结论 | 被否方案与原因 |
|---|---|---|
| 是否重写 claude-swap | **不重写**，App 只做界面，核心逻辑调命令行 | 用 Rust + Tauri 全量重写：2.2 万行有效代码 + 4.4 万行测试、691 次提交的边角修补，6–10 周且有令牌被吊销的风险；上游每月几十次更新，重写等于分叉 |
| 界面技术 | **原生 Swift（AppKit 状态栏 + SwiftUI 面板）** | Tauri：网页引擎常驻占内存、观感不原生；本机只需 Mac |
| 命令行做不到的 | **App 自己做**（用户原话：「功能不变，App 能做的就自己做」） | 砍掉相应功能 |
| App 名称 | **cswap**（用户指定） | — |

## 用户明确的设计要求（逐条）

- 风格参考 NetHub，但**不照搬结构**：需要的才加，加之前想清楚合理做法。
- 用量显示**已使用量**；「回满」→「刷新」。
- 账号列表要有、要好看；当前账号**整行背景高亮**，不写「使用中」。
- 头像用 **Claude 图标，圆形**；Free 也用 Claude 图标（灰 / 白）；Free / Pro / Max 5x / Max 20x 徽章各不相同；到期徽章不要用原来那种（已改为灰底 + 橙色「已到期」）。
- 菜单栏图标用 **Claude App 自带的托盘模板图**。
- 底部右侧是**齿轮**，点开通用设置（之前画得像深浅模式切换，已改）。
- 改名：切换线 / 什么时候换 → **切换阈值**；换到哪个号 → **切换优先级**；有效至 → **有效期至**；换号后至少隔 → **切换冷却**；本周单独一条线 → **本周额度单独设阈值**。
- 登录失效：**不要大段提示框**，只在账号下方一行红字，右侧按钮是「刷新」（在终端重新登录后点它）。
- 主面板不放：顶部数据条、运行中的会话列表。

## 已更正的错误

- 切换记录里曾标「手动」：cswap 日志不区分手动 / 自动，该标签是编造的。改为 App 自己记录来源（面板 / 自动），日志里有而 App 没记到的标「命令行」。
- 账号详情曾写「令牌状态：正常，可自动续期」：JSON 拿不到续期信息，改为只显示正常 / 已失效 / 需要重新登录。

## 第一轮真机验收后的修改（2026-11-07）

| 决策 | 结论 | 被否方案与原因 |
|---|---|---|
| 上游菜单栏 | **App 里不留任何检测 / 停用逻辑**（用户：以后不会安装） | 检测上游服务并提供「停用」按钮 |
| 菜单栏显示选项 | **5 小时 / 本周 / 两者（默认）**，两者时上下两行；Claude 图标 16 → 18pt | 「最紧的一项」「只要图标」（用户不要） |
| 用量卡布局 | 两张卡**仍左右并排**；本周卡变粗是均速竖线把进度条撑高的 bug，已修 | 两张卡各占一行（问题不在布局，且多占高度） |
| 账号列表 | 当前账号排最前；行更高、行间留 4pt | — |
| 档位识别 | 以组织类型为准；Pro 不标「已到期」（用户确认 1 号订阅未到期） | 照搬 cswap 的 label / expired（对 Pro 不准） |
| 别名 | App 自己存（支持大小写、中文） | 写 cswap 的 alias（强制小写、只允许 `[a-z0-9_.-]`） |
| 单账号切换阈值 | 「单独设切换阈值」开关 + 打开后出现滑块（与「本周额度单独设阈值」同一做法） | 展开后「跟随全局 / 自定义」分段（用户：不好看） |
| 用量卡布局（再改） | **先试各占一行**（用户要求；不好看再还原）：一行文字（标签、刷新时间、数值）+ 进度条。还原只需把 `UsageCards.layout` 改回 `.sideBySide` | — |
| 时间显示 | **24 小时制、本机系统时区**（读 `/etc/localtime`，不受 TZ 环境变量影响）；调用 cswap 时去掉 TZ，日志也按系统时区记 | 用 TimeZone.current（会被终端里的 `TZ=Europe/Oslo` 带偏） |
| 上游菜单栏 | 已卸载：服务用 `cswap menubar --uninstall-service` 移除，`claude-swap Menubar.app` 移到废纸篓（可放回） | — |
| 面板闪烁 | 根因：内容视图四边钉死，Auto Layout 按左下角不动去撑窗口（先向上长再被挪回）；滚动区「先量后设」多一帧中间态。改为只钉顶边、在同一轮布局里调窗口高度；滚动区用一次布局定高的 CapHeight | 异步（下一轮）再调窗口高度 |
| 用量卡布局（定） | **左右并排**（各占一行试过，用户：不好看） | 各占一行 |
| 账号行「⋯」按钮 | **去掉**：点账号行进详情，行内只留「切换」（失效时「刷新」）；右键菜单保留 | 「⋯」菜单（与详情重复） |
| 面板窗口尺寸 | NSHostingController 报告理想高度、内容铺满并贴顶，窗口随之调整、顶边不动 | 四边约束撑窗口（闪烁）；只钉顶边并在布局中改窗口（顶部被截掉、底部空白） |
| 版本号 | 同 NetHub：`Version.swift` 唯一来源 + CHANGELOG + release 打标签；首个版本 **0.1.0**；介绍「Claude Code 账号切换（搭配 Claude-cswap）」只写进 Info.plist（访达简介里那行），设置页底部只显示版本 | 1.0.0；设置页底部也放介绍 |
| 可点击处 | 鼠标变小手（macOS 15+ 用系统指针样式） | — |
| 用得偏快 / 预计用完 | 按当前速度撑不到刷新就算偏快（cswap `willLastToReset`）；「预计周二 09:55 用完」与刷新时间在本周卡底行轮流显示（向上推，各 3 秒），去掉卡片下方的节奏提示行（用户 2026-11-08） | 沿用 cswap `aheadOfPace`（超均速 15 个点才算，超 11 个点、会早一天多用完仍显示「充足」）；卡片下方单独一行提示 |
