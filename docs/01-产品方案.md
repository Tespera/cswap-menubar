# cswap · 产品方案

> 状态：设计已定稿（2026-11-07），尚未开始编码。定稿设计稿：`design-demos/a4.html`。

## 1. 是什么

**cswap** 是一个 macOS 菜单栏 App，给 [claude-swap](https://github.com/realiti4/claude-swap)（Claude Code 多账号切换命令行工具，命令名 `cswap`）做一个好看、好用的图形外壳，替换它自带的纯文字菜单栏。

- 账号、令牌、用量、自动切换的**核心逻辑全部交给命令行 cswap**，App 不重写这些逻辑，只调命令、读 JSON。
- 命令行不提供、但界面需要的东西，由 **App 自己做**（见 `02-功能清单.md` 的「App 自建」列）。
- 只给本机自用，macOS 27，浅色 / 深色都要支持。

## 2. 为什么做

上游自带的菜单栏（`cswap menubar`）用 Python 的 rumps 库，只能画系统下拉文字菜单：没有进度条、颜色、卡片，信息全挤成一行行文字。改样式改不好，只能换掉界面层。

## 3. 使用者与场景

- 唯一使用者：本机用户，重度 Claude Code 用户，目前 2 个账号（以后可能更多）。
- 一天瞄几十次菜单栏，每次 2 秒，只想知道：**现在这个号还够不够、什么时候刷新、要不要换**。
- 偶尔：换号、处理登录失效、调自动切换规则。

## 4. 设计原则（用户在评审中确认过的）

1. **风格参考 NetHub**（`/Volumes/Work/VibeCoding/NetHub`）：原生毛玻璃面板、13 / 12 / 10 pt 字号、半透明小卡片配 0.5px 细边、底部图标工具栏、浅深色同步。**只参考风格，不照搬结构**——内容按需要取舍，加之前先想清楚合理的做法。
2. **数字一律显示已用量**（不是剩余量）；时间一律说「刷新」（不说「回满」「重置」）。
3. 结论先行：顶部一个状态点告诉你「充足 / 用得偏快 / 快到切换阈值 / 已用完」。
4. 提示只在需要时出现，正常时面板保持短。
5. 文案用大白话，不出现 best、threshold、cooldown 这类词。

## 5. 界面结构（定稿）

```
菜单栏：[Claude 模板图标] 30%/68%    ← 当前账号 5 小时、本周已用量（上下两行，可只显示一项）；≥ 85% 橙、用完红
点开 ↓
┌ 主面板 ─────────────────────────────┐
│ (●) alicechen92  [✻ Pro]   ● 用得偏快 │  头部：圆形 Claude 头像、名字、档位徽章、状态
│ ┌ 5 小时 ── 58% ┐ ┌ 本周 ──── 67% ┐   │  两张用量卡（已用量；本周卡竖线=均速位置）
│ │ ▓▓▓▓▓░░░░     │ │ ▓▓▓▓▓▓|░░░    │   │
│ │ 2 时 50 分后刷新│ │ 周三 05:00 刷新 │   │
│ （本周卡底行：周三 05:00 刷新 ⇄ 预计周二 09:55 用完）│  ← 撑不到刷新时轮流显示
│ 账号                          + 添加   │
│ [当前账号整行浅蓝底]  名字 [徽章]  ⋯     │  账号列表（Wi‑Fi 菜单式）
│ (灰头像) 名字 [徽章]  5h ▬ 0% 本周 ▬ 64% [切换] ⋯ │
│ ─────────────────────────────────── │
│ ⇄ 自动切换  用到 90% 时换到余量最多的号  (开关) › │
│ ─────────────────────────────────── │
│ ⟳  刚刚更新                       ⚙  │  底部：刷新、更新时间、设置
└─────────────────────────────────────┘
```

面板内部推入式导航（左上角返回，不另开窗口）：

| 页面 | 入口 |
|---|---|
| 账号详情 | 点账号行 / 「⋯」菜单 →「账号详情…」 |
| 自动切换设置 | 点「自动切换」那一行（开关本身直接切换开/关） |
| 通用设置 | 底部齿轮 |
| 切换记录 | 通用设置 →「切换记录」 |

账号「⋯」按钮 / 右键菜单：切换到这个账号、账号详情…、设置别名…、不参与自动切换（勾选态）、用这个号开一个终端、复制邮箱、移除账号…（红色）。

详细视觉规范见 `03-界面与设计规范.md`；完整功能见 `02-功能清单.md`。

## 6. 范围

### 本期做（功能清单里的全部「必做」）
主面板、账号列表与全部账号操作、账号详情、自动切换（开关 + 全部设置 + 后台运行）、通用设置、系统通知、切换记录、cswap 版本检测与升级、登录时打开。（上游菜单栏的检测与退役已按用户要求去掉，见 07）

### 待定（用户尚未表态，不要自行开工）
全局快捷键、备份与恢复（export/import）、文件夹绑定账号（map）、用量历史曲线、快捷指令支持。

### 不做
setup-token / API Key 账号的添加（`add-token`）、槽位交换（swap/move）、导入别的机器的用量（import-usage）、彻底清除数据（purge）、`cswap run` 的并行会话管理。频率极低，留给命令行。
