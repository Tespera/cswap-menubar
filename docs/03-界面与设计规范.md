# cswap · 界面与设计规范

定稿设计稿：`design-demos/a4.html`（浏览器打开；顶部可切「现在 / 四个档位 / 快到切换线 / 登录失效」四个场景和浅色 / 深色）。实现以它为准，本文件把它拆成可实现的规则。

> `design-demos/` 里其他文件是被否掉的历史稿（见 `07-决策记录.md`），不要参考。

## 1. 视觉基调

- 风格参考 NetHub：直接复用 NetHub 的 `Sources/NetHubUI/Theme.swift`（字体 `F.sys / F.num`、色板 `T.*`、`Segmented`、`Switch`、`Hairline`、`card()`、`hoverHighlight()`、`SmallButtonStyle`），复制过来改名，不跨仓库依赖。
- 面板：宽 320pt，圆角 12，系统毛玻璃（等价 `.ultraThinMaterial`）；浅色底 `rgba(244,244,246,.8)`，深色底 `rgba(38,38,42,.78)`。
- 卡片：`T.card`（浅 白 60%，深 白 6%）+ 0.5pt `T.sep` 描边，圆角 9。

## 2. 字号（pt，全部基于 NSFont，不随系统文字大小缩放）

| 用途 | 字号 / 字重 |
|---|---|
| 头部名字、子页标题 | 13 semibold |
| 正文、行标题、按钮 | 12 medium（按钮 11 medium） |
| 用量卡数值 | 12.5 semibold，等宽数字；% 号 9.5 |
| 次要说明、行副标题 | 10.5 |
| 卡片标签（5 小时 / 本周）、分组标题 | 10 semibold，`T.t3` |
| 迷你条旁数字、底部更新时间 | 10，等宽数字 |
| 账号行迷你条下的刷新时间 | 9.5，等宽数字，`T.t3` |
| 档位徽章 | 9.5 semibold |

## 3. 颜色语义

| 语义 | 浅色 | 深色 | 用在 |
|---|---|---|---|
| 5 小时进度 | 系统蓝 #0A84FF | 同 | 5 小时进度条 |
| 本周进度 | #2FB350 | #32D74B | 本周进度条 |
| 警告 | #C46F00 | #FFB340 | 已用 ≥ 85%、用得偏快、到期后缀 |
| 危险 | #D3271C | #FF6961 | 已用 100%、登录失效、移除 |
| 强调 / 当前账号高亮 | 系统强调色 12% 透明度铺底 | 同 | 当前账号整行、开关、选中分段 |

> 警告与危险色比 NetHub 原色深一档（#E38A00 → #C46F00、#E5372C → #D3271C），保证浅色下文字对比度 ≥ 4.5。

进度条颜色规则（已用量 u）：u ≥ 100 → 危险；u ≥ 85 → 警告；否则用该窗口的本色。

## 4. 状态判定（头部状态点，纯函数，写单元测试）

取当前账号 `t = max(5 小时已用, 本周已用)`：

1. t ≥ 100 → 红「已用完」（其他可用账号也都 ≥ 100 → 「都已用完」）
2. t ≥ 85 → 橙「快到切换阈值」
3. 本周按当前速度撑不到刷新（`willLastToReset=false` 且 `projectedExhaustionAt` 早于刷新；刷新后头 24 小时不判）→ 橙「用得偏快」。不用 `aheadOfPace`：它要超过均速 15 个点才算
4. 否则 → 绿「充足」

菜单栏百分比颜色与状态点同级（绿 = 系统默认色，不着色）。

## 5. 头像与档位徽章

**头像**：圆形 Claude 图标（`assets/claude-icon-2048-bright.svg` 的星形，橙色渐变 #E97A56→#EC6B41 圆底 + 白星，星形缩到直径约 60%）。
- 当前账号：彩色
- 其他账号：灰度 + 45% 不透明
- 不参与自动切换 / 登录失效：灰度 + 25% 不透明
- 尺寸：头部 22，列表 26，详情 38

**档位徽章**（高 16，圆角 5，左侧 9pt Claude 星形 + 文字）：

| 档位 | 来源字段 | 样式 |
|---|---|---|
| Free | `plan.tier = default_claude_ai` | 描边 0.5pt，灰色星，灰字 |
| Pro | `plan.organizationType = claude_pro` 等（label「Pro」） | 浅橙底（#EC6B41 14%），橙字 #C2501F（深色 #FF9A72） |
| Max 5x | `default_claude_max_5x` | 实心橙渐变 #EE8460→#E2582E，白字 |
| Max 20x | `default_claude_max_20x` | 深底渐变 #3A2219→#22130D，橙色星 #FF9A62，浅杏字 #FFE1C8，0.5pt 橙色内描边 |
| Team | `organizationType = claude_team` | 蓝色浅底（#2E6BD6 13%），团队小图标 |
| 已到期 | `plan.expired = true` | 灰底（`T.track`）、灰星、原档位名 + 橙色「已到期」 |
| 未知 | 其他 tier 字符串 | 同 Free 样式，显示 cswap 给的 label 原文 |

**档位识别规则（App 端纯函数，写测试）**——cswap 的 `plan.label` 只对已观察到的 tier 做了映射（Free / Max 5x / Max 20x / Team），**Pro 档没有映射，有效 Pro 账号的 tier 原文未实测**：
（2026-11-07 用户实测更正）cswap 的档位只看额度等级（rate_limit_tier），**Pro 的额度等级与 Free 相同**（`default_claude_ai`），所以 cswap 把有效 Pro 标成 Free、把关掉自动续费（状态 canceled）但仍在有效期内的 App Store Pro 标成已到期。以组织类型为准：
1. `plan.expired = true` 且组织类型**不是** Pro → 「已到期」（Max 类原档位名写 Max）。Pro 的到期从 cswap 数据里判断不了，不标。
2. 组织类型 / label 为 Team → Team；额度等级含 max_20x / max_5x → Max 20× / Max 5×；组织类型含 pro → Pro；label 为 Free → Free。
3. tier 或 organizationType 含 `pro` → Pro。
4. 其他 → 「未知」样式，显示 label 原文。
拿到第一个有效 Pro / Max 账号的真实输出后，补进 `fixtures/` 和测试。

## 6. 文案表（统一用词，实现时照抄）

| 场景 | 用词 |
|---|---|
| 窗口名 | 5 小时 / 本周（额度） |
| 时间 | 「2 时 50 分后刷新」「周三 05:00 刷新」；撑不到刷新时本周卡底行与「预计周二 09:55 用完」（橙）轮流显示，各停 3 秒、向上推切换；24 小时以内用相对时间，超过用星期 + 时刻；一律 24 小时制、本机系统时区（不受 TZ 环境变量影响） |
| 设置项 | 切换阈值、本周额度单独设阈值、切换优先级、切换冷却、也看模型周限额、API Key 账号也参与 |
| 策略 | 余量最多的（默认，最稳）/ 本周最先刷新的（到线才换，先用掉快作废的额度）/ 始终用最先刷新的（不到线也会换，尽量不浪费）/ 按我排的顺序（先用完优先级高的，在账号详情里排） |
| 登录 | 有效期至、令牌状态、登录已失效，在终端重新登录后点刷新 |
| 菜单 | 切换到这个账号、账号详情…、设置别名…、不参与自动切换、用这个号开一个终端、复制邮箱、移除账号… |
| 底部 | 刚刚更新 / N 分钟前更新 / 读取失败，N 分钟后重试 |

不出现：使用中、回满、重置、切换线、best / threshold / cooldown 等英文词、中点「·」串联元信息。中英文、数字与单位之间加空格（同 NetHub 规则）。

## 7. 交互细节

- 面板内子页推入：左上角「<」返回；子页标题 13 semibold，下方 0.5pt 分隔线。
- 账号行：整行可点 → 详情；「切换」按钮与「⋯」按钮各自响应，不触发进入详情。
- 「⋯」与右键是同一个菜单（系统 NSMenu）。
- 自动切换行：开关直接切换；点开关以外区域进入设置页。
- 移除账号：系统确认对话框，按钮「移除」为危险样式。
- 自动切换设置页内容较长，面板要能滚动（最大高度跟随屏幕可用高度）。
- 动效：只在页面推入 / 返回、开关切换时有（0.15–0.2s easeOut）；尊重「减少动态效果」。
