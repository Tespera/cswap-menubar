# cswap · 功能清单

每项标明数据 / 动作的来源：**CLI** = 调命令行 cswap；**App** = App 自建（命令行不提供）；**CLI+App** = 命令行有，但要 App 补一层。命令细节、坑和验证结论见 `05-cswap命令行对接.md`。

优先级：P0 = 没有就不能用；P1 = 本期必做；待定 = 用户未表态，不开工。

## C. 账号操作与账号详情

| # | 功能 | 来源 | 优先级 | 说明 |
|---|---|---|---|---|
| C1 | 账号详情页：大头像、名字、徽章、邮箱、两张用量卡 | CLI | P1 | |
| C2 | 有效期至（登录） | CLI（`loginExpiresAt`） | P1 | 没有该字段显示「—」 |
| C3 | 令牌状态：正常 / 已失效 / 需要重新登录 | CLI（`usageStatus`） | P1 | **只能到这一级**：详细令牌信息只有文字版，`--token-status` 与 `--json` 互斥 |
| C4 | 参与自动切换（开关） | CLI（`disable` / `enable`） | P1 | |
| C5 | 切换阈值（单账号）：跟随全局 / 自定义 50–99.9% | CLI（`threshold N pct` / `--unset`；读 `threshold` 字段） | P1 | |
| C6 | 优先级（0–1000，− / + 步进） | CLI+App | P1 | 写：`priority N tier`；**读：JSON 里没有**，要解析 `cswap priority` 文字输出（样例 `fixtures/priority.txt`）。只在策略「按我排的顺序」时生效，界面写明 |
| C7 | 别名 | App | P1 | App 自己按邮箱保存（`names.json`）：cswap 的别名只允许小写字母、数字和 `_.-` 并强制转小写，满足不了大小写 / 中文。没在 App 里设过的显示 cswap 的 `alias` |
| C8 | 用这个号开一个终端 | CLI（`run N`）+ App | P1 | App 生成临时 `.command` 文件交给「终端」打开，避免申请自动化权限 |
| C9 | 登录失效后的「刷新」 | CLI（`add --slot N`）+ App | P1 | 先 `status --json` 核对**当前登录的邮箱就是这个账号**，再 `add --slot N`；不是同一个号就提示「当前登录的不是 XX，请先在终端用它登录」，不执行（否则会把别的号写进这个位置） |
| C10 | 复制邮箱 | App | P1 | |
| C11 | 移除账号（二次确认） | CLI+App | P1 | `remove` 没有跳过确认的参数，会读标准输入问 `[y/N]`：App 界面先确认，再往标准输入写 `y`。账号有运行中的会话时命令会拒绝，要把原因显示出来 |

## D. 自动切换设置

| # | 功能 | 来源 | 优先级 | 说明 |
|---|---|---|---|---|
| D1 | 总开关 | App | P0 | 开 = App 启动并看护 `cswap auto --json` 子进程；关 = 结束它。状态存 App 设置 |
| D2 | 切换阈值 · 5 小时额度（滑块 50–99） | CLI（`config set autoswitch.threshold`） | P1 | |
| D3 | 本周额度单独设阈值（开关）+ 本周额度（滑块 50–99.9） | CLI（`autoswitch.weeklyThreshold`，关 = `config unset`） | P1 | 说明文案：关闭时，本周额度和 5 小时用同一个阈值 |
| D4 | 切换优先级（单选 4 项） | CLI（`autoswitch.strategy`） | P1 | 余量最多的 = `best`（默认）；本周最先刷新的 = `weekly-first`；始终用最先刷新的 = `consume-first`；按我排的顺序 = `priority-consume-first` |
| D5 | 切换冷却：1 / 5 / 10 / 30 分钟 | CLI（`autoswitch.cooldownSeconds` = 60/300/600/1800） | P1 | 说明：换号后这段时间内不再自动换，免得来回跳 |
| D6 | 也看模型周限额（选一个模型或「不看」） | CLI（`autoswitch.model`；可选模型名取 `usage.scoped`） | P1 | 没有任何 scoped 窗口时整行隐藏 |
| D7 | API Key 账号也参与 | CLI（`autoswitch.includeApiKeyAccounts`） | P1 | |
| D8 | 设置改动后自动重启 auto 子进程 | App | P1 | |

## F. 系统通知

| # | 场景 | 来源 | 文案示例 |

| # | 功能 | 来源 | 说明 |
|---|---|---|---|
| G1 | 最近 10 次切换：换到谁、时间、来源 | CLI 日志 + App | cswap 日志只有 `Switched from account X to Y`，**不区分手动 / 自动**。App 自己记录经它发起的切换（来源「面板」）和 auto 事件（来源「自动」），存 App 数据目录；日志里有、App 没记录到的标「命令行」 |

## H. cswap 命令行管理

| # | 功能 | 来源 | 说明 |
|---|---|---|---|
| H1 | 找到 cswap | App | 依次找 `~/.local/bin/cswap`、登录 shell 的 PATH；找不到 → 面板显示安装引导（`uv tool install 'claude-swap[menubar]'`，走镜像） |
