cswap 菜单栏 · 第三版：完整功能

在第二版的基础上补齐了账号操作、自动切换设置和通用设置；头像改成圆形 Claude 图标；Free、Pro、Max 5x、Max 20x（另加 Team）各有一个徽章。「现在」是你两个账号刚刚（07:19）读到的真实数据，其余场景为示例数据。

场景
外观
作为独立 App，这一版已经加进来的
  1. 账号详情页：用量、登录有效期、别名、是否参与自动切换、单独切换线、优先级，以及切换、开终端、移除。
  2. 右键和「⋯」菜单：常用账号操作不用进详情页。
  3. 自动切换设置：5 小时和本周两条切换线、换到哪个号、换号后的冷却时间、是否盯某个模型的周限额、API Key 账号是否参与。
  4. 通用设置：菜单栏显示什么、刷新频率、三类通知、登录时打开、切换记录。
  5. cswap 命令行的版本检测与升级：App 靠它干活，没装、版本太旧都要能看到并一键处理，升级后自动重启后台。
  6. 令牌失效的账号：面板里直接给出红色提示和修复步骤，不用去翻日志。
还可以加，但要你来定（这版没画）
  • 全局快捷键：按一下打开面板，或直接换到余量最多的号。
  • 备份与恢复：把所有账号导出成一个文件，换电脑时导入。
  • 文件夹绑定账号：在某个项目目录里打开 Claude Code 时自动用指定的号。
  • 用量历史图：cswap 本身不存历史，要 App 自己每隔一段时间记一笔，才能画出一周曲线。
  • 快捷指令支持：让「快捷指令」App 或脚本能切号、查用量。
